# Omgezet vanuit environment.yaml (conda) naar pip.
# Installeren (na het aanmaken en activeren van je venv):
#   pip install -r requirements.txt
#
# Let op 1: 'graphviz' hieronder is alleen de Python-wrapper.
#   De tekentool zelf (het programma 'dot') installeer je apart met:
#   brew install graphviz
#
# Let op 2: torchinfo heeft GEEN dependency op torch (torchinfo's "Requires"
#   is leeg) — torch moet dus los in dit bestand staan, anders krijg je
#   "ModuleNotFoundError: No module named 'torch'".
#
# Let op 3: op een Intel Mac (x86_64) is torch 2.2.2 de laatste versie die nog
#   een macOS x86_64 wheel heeft (latere torch-versies zijn alleen voor Apple
#   Silicon/arm64). Die build is gelinkt tegen NumPy 1.x, dus numpy moet <2
#   blijven — met numpy 2.x geeft "import torch" een NumPy-compatibiliteits-
#   waarschuwing/crash. numpy<2 is ook veiliger voor gensim (zie hieronder).
#
# Let op 4: torchvision moet exact bij de torch-versie passen (0.17.2 hoort
#   bij torch 2.2.2) — een niet-matchende versie geeft import- of
#   runtime-fouten.
